# 비교급: as ~ as / than

원급 비교(동등)와 비교급 비교(우열)를 한 번에 정리합니다.

## 한눈에 보기

| 의미 | 구문 |
|---|---|
| A = B (동등) | A is **as** 원급 **as** B |
| A < B (열등) | A is **not as** 원급 **as** B / A is **less** 원급 **than** B |
| A > B (우등) | A is 비교급 **than** B |

## 1. 원급 비교: as + 원급 + as

**A + 동사 + as + 형용사/부사 원급 + as + B** : A는 B만큼 ~하다

- **He is as tall as his father.** 그는 아버지만큼 키가 크다.
- **She runs as fast as I do.** 그녀는 나만큼 빨리 달린다.

**부정: not as(so) + 원급 + as** : A는 B만큼 ~하지 않다

- **This book is not as interesting as that one.** 이 책은 저 책만큼 재미있지 않다.

### 자주 쓰는 as ~ as 표현

| 표현 | 의미 | 예문 |
|---|---|---|
| 배수 + as + 원급 + as | ~의 몇 배 | This is **twice as big as** that. |
| as + 원급 + as possible | 가능한 한 ~하게 | Come **as soon as possible**. |
| as many(much) + 명사 + as | ~만큼 많은 | I have **as many books as** you. |
| the same + 명사 + as | ~와 같은 … | He has **the same bag as** mine. |
| as good as | ~나 다름없는 | The work is **as good as** done. |

## 2. 비교급 비교: 비교급 + than

**A + 동사 + 비교급 + than + B** : A는 B보다 더 ~하다 (우등)

- **She is taller than her brother.** 그녀는 오빠보다 키가 크다.
- **This problem is more difficult than that one.** 이 문제는 저 문제보다 어렵다.

**less + 원급 + than** : A는 B보다 덜 ~하다 (열등)

- **This car is less expensive than that one.** 이 차는 저 차보다 덜 비싸다.

### 비교급 만드는 법

| 유형 | 규칙 | 예 |
|---|---|---|
| 1음절 / 일부 2음절 | -er | tall → taller, easy → easier |
| 2음절 이상 대부분 | more + 원급 | beautiful → more beautiful |
| 단모음 + 단자음 | 자음 반복 + er | big → bigger, hot → hotter |
| 자음 + y | y → i + er | happy → happier |
| 불규칙 | 외우기 | good/well → better, bad/ill → worse, many/much → more, little → less, far → farther(거리) / further(정도) |

### 비교급 강조

**much / far / even / still / a lot + 비교급 + than**

- **This is much better than that.** 이것이 저것보다 훨씬 좋다.
- 주의: very는 비교급을 강조할 수 없습니다. (✕ very better → ○ much better)

## 3. than 뒤에서 자주 틀리는 점

1. **같은 것끼리 비교하기** (that of / those of로 반복 피하기)
   - ✕ The population of Seoul is larger than Busan.
   - ○ The population of Seoul is larger than **that of** Busan.
2. **비교급 앞에는 보통 the를 안 붙입니다.** 최상급과 구분하세요.
   - She is **taller than** I. / She is **the tallest** in the class.
3. **as ~ as 사이에는 원급만 씁니다.**
   - ✕ as taller as → ○ as **tall** as
4. **than 뒤 대명사:** 회화에서는 than me도 쓰지만, 문어체는 than I (do)입니다.

## 4. 비교급 관용 표현

| 표현 | 의미 | 예문 |
|---|---|---|
| the + 비교급 ~, the + 비교급 … | ~할수록 더 …하다 | **The more** you read, **the more** you know. |
| 비교급 and 비교급 | 점점 더 ~한 | It gets **colder and colder**. |
| no more than | 겨우 ~ (적다는 강조) | He has **no more than** 10 dollars. |
| not more than | 많아야 ~ | There were **not more than** 10 people. |
| no less than | ~나 되는 (많다는 강조) | He has **no less than** 100 books. |
| not less than | 적어도 ~ | It costs **not less than** 50 dollars. |
| A is no more B than C is D | C가 D가 아니듯 A도 B가 아니다 | A whale is **no more** a fish **than** a horse is. |
| superior / inferior / senior / junior / prefer + to | than 대신 to를 씁니다 | I **prefer** tea **to** coffee. |

## 내 문장 만들기

- [ ] as ~ as 문장 2개 쓰기
- [ ] 비교급 + than 문장 2개 쓰기
- [ ] the + 비교급 ~, the + 비교급 … 문장 1개 쓰기

## 복습 체크

- [ ] 동등 / 열등 / 우등 구문 세 가지를 말할 수 있다
- [ ] 불규칙 비교급 (good, bad, many, little, far)을 외웠다
- [ ] than 뒤 비교 대상이 같은 종류인지 확인한다
